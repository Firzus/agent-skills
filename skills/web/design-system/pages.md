# Page catalog

Per-category catalog of pages, their key sections, and the placeholder content to prototype during greyboxing. Load only the categories selected in Phase 0.

## Marketing / public

| Page                        | Key sections                                                                 | Placeholder content to prototype                          |
| --------------------------- | ---------------------------------------------------------------------------- | --------------------------------------------------------- |
| Home / landing              | hero (headline, subheadline, primary CTA), social-proof strip, features overview, testimonial, final CTA | hero copy, 3–6 feature blurbs, client logos, one quote     |
| About                       | story, mission/values, team grid, milestones                                 | founding story, 3–5 values, team names/roles/photos        |
| Pricing                     | plan cards, feature comparison table, FAQ teaser, CTA                        | 2–4 plans with prices, per-plan feature lists              |
| Features                    | feature detail blocks (alternating media/text), integrations, CTA            | per-feature headline + paragraph + visual                  |
| Contact                     | contact form, direct channels (email, phone), address/map, hours             | form fields, office details                                |
| Blog                        | post grid/list, categories/tags filter, pagination, newsletter signup        | 6–9 post cards (title, excerpt, cover, date, author)       |
| Blog post                   | title/meta header, cover, article body, TOC, author bio, related posts       | full-length article with headings, images, code/quotes     |
| FAQ                         | grouped questions (accordion), search, contact fallback                      | 8–15 Q&A pairs across 2–4 groups                           |
| Testimonials / case studies | logo wall, quote cards, case-study detail (challenge → solution → results)   | 3+ quotes, one full case study with metrics                |
| Changelog                   | dated release entries, version tags, category badges (added/fixed/changed)   | 5+ release entries                                         |
| Careers                     | culture intro, benefits, open positions list, job detail                     | 3+ job cards (title, team, location), one full job posting |
