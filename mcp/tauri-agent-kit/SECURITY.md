# Security policy

This is privileged, debug-only development tooling, not a sandbox. Only the current alpha is maintained. Do not enable it in untrusted applications or attach a client you do not trust.

Report vulnerabilities through GitHub's private vulnerability reporting on the repository Security tab once enabled. If unavailable, ask the maintainer through an issue for a private reporting channel without including exploit details, logs, tokens or sensitive data. No response-time guarantee is offered.

See [the trust model](docs/security.md) for current-user pipe authentication, advanced-tool authority, data limits and native input races. Screenshots may reveal visible sensitive data.
